# Hope Rise Foundation — End User & Admin Documentation

Welcome to the official user guide for the **Hope Rise Foundation** web application[cite: 1]. This document explains how public visitors interact with the site and how administrators manage content through the control dashboard[cite: 1].

---

## 🌐 Public Website User Guide

### 1. Main Sections
* **About Our Story:** Displays the founding narrative from 2015 and key organizational milestones[cite: 1].
* **Mission & Vision:** Details the foundation's core purpose and community empowerment goals[cite: 1].
* **Core Values:** Outlines key principles: *Integrity, Empathy, Inclusivity, and Transparency*[cite: 1].
* **Active Programs:** Highlights key initiatives:
  * **Free Education Resources:** Provides learning materials and support for children[cite: 1].
  * **Rural Healthcare Camps:** Offers basic medical attention and check-ups in villages[cite: 1].
  * **Vocational Training:** Teaches financial independence skills for women[cite: 1].
* **Impact Metrics:** Displays real-time statistics on beneficiaries served[cite: 1].
* **Leadership Team:** Introduces key leaders, including John Doe (*Founder*) and Jane Smith (*Program Manager*)[cite: 1].

### 2. Community Engagement
* **Donate Now:** Directs users to contribute financial support[cite: 1].
* **Become a Volunteer:** Allows visitors to register as volunteers for local health camps or education programs[cite: 1].

## 🛠 Administrator Portal Guide

The **About Us Admin Dashboard** enables authorized staff to manage website content dynamically[cite: 1].

### Admin Modules Overview

| Module Name | Core Functionality | Available Actions |
| :--- | :--- | :--- |
| **Our Story** | Updates background history and main banner graphics[cite: 1]. | Edit title, body text, and upload images[cite: 1]. |
| **Core Values** | Controls organizational values listed on the site[cite: 1]. | Add, edit, or delete core values[cite: 1]. |
| **Programs** | Manages community programs and activity status[cite: 1]. | Add initiatives, modify details, change status[cite: 1]. |
| **Team Members** | Manages leadership profiles[cite: 1]. | Add staff, update roles, upload headshots[cite: 1]. |
| **Our Impact** | Updates beneficiary counters and key achievement figures[cite: 1]. | Modify numerical KPI metrics[cite: 1]. |
| **Call to Action** | Controls donor and volunteer banner copy and links[cite: 1]. | Edit banner text, button copy, and links[cite: 1]. |

---

## 🗄 System Data Structure

* **`our_story`**: Stores narrative text, section headers, and main cover image path[cite: 1].
* **`core_values`**: Stores individual organizational values independently[cite: 1].
* **`programs`**: Tracks active/inactive program names and descriptions[cite: 1].
* **`team_members`**: Holds staff names, roles, and profile image file paths[cite: 1].
* **`our_impact`**: Stores numerical KPI counters for public display[cite: 1].
